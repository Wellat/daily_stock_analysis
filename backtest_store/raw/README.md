## 口径注意事项

- 末日权益抽查：策略1 = 1,239,323.72、策略2 = 988,624.60，与回测评估值完全一致；策略3 = 995,022.91，与评估值 995,042.91 恰差 20 元——评估值取自同参数 1,000,020 元实例（`01a1105a-…`），数据无误。
- CSV 中调仓日可能出现 `持仓量(张)=0` 的占位记录，为接口原样返回，未做删改。
- 净值曲线（timelines）的 hold_securities 列表比本持仓明细滞后一个交易日，分析时以本数据为准。
- 策略1 未排除强赎，持仓中简称带 `Z` 前缀的标的处于停止交易阶段，其 last_price 为冻结价（回测按冻结价卖出，含乐观假设）。
