## 文件说明

- `策略N_*_每日持仓.csv`：逐日逐标的持仓。字段：交易日、代码、名称、持仓量(张)、成本价、
  最新价、市值、持仓盈亏、是否停牌、当日税后分红、当日送转。注意：调仓于当日收盘成交，持仓明细 API 在成交当日即反映新持仓
  （成本价≈当日收盘价）；而回测净值曲线中的 hold_securities 列表滞后一个交易日。
- `策略N_*_成交变动推导.csv`：由相邻两日持仓快照对比推导的仓位变动（新建仓/加仓/减仓/清仓）。
  **平台未提供逐笔成交接口**，此文件为推导结果：成交价为估算（买入按当日成本价、卖出按前收市值价），
  同日先买后卖会被净额抵消，仅供复盘参考，不等同于官方成交流水。
- `全策略_账户每日汇总.csv`：五个回测的账户级逐日数据（权益、持仓市值、余额、累计盈亏、持仓只数）。
- `raw/策略N_*_持仓原始返回.jsonl`：接口原始返回，未做任何加工，可用于核对或重新导出。

## 已知口径说明

1. 持仓快照的 `cost_price` 为摊薄成本；`profit_loss` 为相对成本价的浮动盈亏（账户级为累计已实现+浮动口径，以平台定义为准）。
2. 首个调仓日为 2026-01-05（当日收盘建仓，持仓 API 当日即有快照）。
3. 转债强赎/到期导致的被动退出与主动卖出在快照层面不可区分，统一记为「卖出(清仓)」。
4. 生成时间：2026-10-04。
