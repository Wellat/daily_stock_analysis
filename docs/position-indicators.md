# 持仓总览技术指标与止损位

持仓总览（Web 持仓页 → 持仓明细）为每个持仓提供技术指标增强列与行展开详情；持仓元数据支持人工维护止损价，联动周复盘风险清单。

## 指标口径

所有指标由 `stock_daily` 收盘/成交量序列**服务端现算**（表内 `ma5`/`ma20`/`volume_ratio` 列当前不入库、`pct_chg` 仅场外基金有值，均不可直接使用），端点为 `GET /api/v1/portfolio/positions/indicators?account_id=`（缺省全部活跃账户）。

| 指标 | 口径 |
| --- | --- |
| MA5 / MA10 / MA20 | 最近 N 根收盘简单均线；K 线不足 N 根时为空 |
| 均线形态 trend_pattern | `bull`（MA5>MA10>MA20）/ `bear`（反之）/ `mixed`（纠缠）/ `unknown`（均线不足） |
| 乖离 bias_ma5/10/20_pct | 最近收盘 ÷ 对应均线 − 1（百分数） |
| 连涨连跌 streak_days | 从收盘序列末尾比较，带符号（正=连涨，负=连跌）；主表以 `↑N`/`↓N` 徽标展示 |
| 周涨跌 / 月涨跌 | 最近收盘 ÷ 5/20 根前收盘 − 1 |
| 52 周位置 pos_52w_pct | 最近 ~250 根收盘在高低区间中的位置（0=区间最低，100=最高） |
| 量比 volume_ratio | 最新成交量 ÷ 前 5 根均量；**场外基金（.OF）恒为空**（无成交量概念，净值滞后 1-2 天） |
| 迷你曲线 sparkline | 最近 60 根 {date, close}，行展开详情绘图用 |
| 持有天数 holding_days_by_account | 按账户取最早未平仓 lot 的开仓日距今天数；早于等于该账户首笔成交日的 lot 为记账起点导入，天数为下界 |

每个标的带 `last_bar_date` 标注行情新鲜度；行情缺失的标的返回全空占位，不阻塞整体响应。指标接口失败时前端仅将新列降级显示为 `--`，不影响持仓总览。

## 转债行自适应

转债持仓（category=convertible_bond）的均线形态列与量比列分别替换为：

- **转股溢价率**（最新因子日 `strategy_lab_cb_daily_factors.premium_rate`，百分数）
- **临期提醒**：距到期 ≤90 天时显示 `N天到期`（橙色），悬浮 title 显示强赎进度原文

行展开详情的转债面板补全：价格带（≤110 / 110-130 / 130-150 / >150）、剩余规模（亿）、距到期天数、强赎进度原文（`terms_json.force_redeem_countdown`，如 `0/15 | 30`，不做数值解析）。

## 行展开详情

持仓行首 chevron 点击展开：

- 近 60 日收盘迷你曲线（标注行情截至日期）
- 指标网格：乖离 MA5/10/20、周/月涨跌、52 周位置、持有天数、止损价、量比（转债为溢价率）
- 转债附加面板（价格带/剩余规模/到期/强赎进度）
- 买入逻辑说明（buy_logic_text）与备注全文

## 止损位（stop_loss_price）

- 存储：`portfolio_position_meta.stop_loss_price`（正数，可空；老库自动补列）
- 维护：持仓「编辑」弹窗数字输入（留空/清空 = 删除；0/负数被请求校验拒绝）
- 消费方：
  - 持仓总览「距止损」列 = 现价 ÷ 止损价 − 1；≤5% 红色加粗，未设置显示 `--`
  - 周复盘风险清单：距止损 ≤5% 的持仓生成 `stop_loss_near`（severity=high）条目
  - 可作为告警规则 `price_cross` 手动建规则的输入参考（暂未自动联动）
